2) Aadhaar transactions – Excel upload

Two formats are recognised automatically:
1. Division × Date grid – dates in the first row, division names in the first column, total transactions inside (for example the "VC 15 may 26" sheet).
2. Office-wise monthly sheet – dates in row 1, "Total Enrolment / Total Update" in row 2, one row per office (for example the Oct 25 / Dec 25 / Feb 26 sheets). The division total (Enrolment + Update) is calculated automatically.
If a workbook contains several sheets, you will be asked which sheets to import.

Aadhaar machines and number of SOs (division-wise)

No. of SOs is pre-filled from "Total Offices" in the Nil Booking Report (Indore City 34, Mfl 51, Khandwa 51, Mandsaur 35, Ratlam 38, Sehore 33, Ujjain 54 = 296). To use a different SO count for a particular day, edit the value in that day's row on the division tab of the report.

Prior-year baseline row

The baseline row of each month automatically shows the same month of the previous year (MO, Parcel, IRGB, Aadhaar transactions). Per-day average = Total Transactions ÷ Machines ÷ 25.

Product → Category mapping

Products containing "International" are always counted as IRGB. Changing the mapping does not require re-uploading the CSV – the report is rebuilt immediately with the new mapping.
