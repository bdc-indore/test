Target & Achievement – Revenue and Article Count (division-wise, FY 2026-27)

The month's article count and revenue (sum of postage) are filled automatically from the uploaded CSV (division-wise or post-office-wise), per division and per vertical. All % columns are calculated. Revenue: Parcel and MO in crore, IRGB in lakh. Download is enabled once the data is complete.

1A) Daily CSV upload – DIVISION-wise file (MO / Parcel / IRGB data)

Existing data for the dates contained in the file is replaced (no duplicates are created). Any product name containing "International" is counted as IRGB.
This option reads only the division-name column of the file.

1B) Daily CSV upload – POST OFFICE-wise file (MO / Parcel / IRGB data)

The division column of this file is ignored. Only the office-id is read and its division is taken from the Office ID master (built in; you can load your own master sheet in Settings). Data of the dates in the file is replaced. If an Office ID is not in the master, an error is shown and it appears in Settings → Unknown offices where you write its division.

2) Aadhaar transactions – Excel upload

Two formats are recognised automatically:
1. Division × Date grid – dates in the first row, division names in the first column, total transactions inside (for example the "VC 15 may 26" sheet).
2. Office-wise monthly sheet – dates in row 1, "Total Enrolment / Total Update" in row 2, one row per office (for example the Oct 25 / Dec 25 / Feb 26 sheets). The division total (Enrolment + Update) is calculated automatically.
If a workbook contains several sheets, you will be asked which sheets to import.

Aadhaar machines and number of SOs (division-wise)

No. of SOs is pre-filled from "Total Offices" in the Nil Booking Report (Indore City 34, Mfl 51, Khandwa 51, Mandsaur 35, Ratlam 38, Sehore 33, Ujjain 54 = 296). To use a different SO count for a particular day, edit the value in that day's row on the division tab of the report.

Prior-year baseline row

The baseline row of each month automatically shows the same month of the previous year (MO, Parcel, IRGB, Aadhaar transactions). Per-day average = Total Transactions ÷ Machines ÷ 25.

Unknown offices (Office ID → Division)

Columns: office-id and division-name. These entries override the built-in master.
Used only for the post-office-wise CSV (1B). An office whose division cannot be found is listed here – write its division and save; it is remembered for the next uploads.

Product → Category mapping

Products containing "International" are always counted as IRGB. Changing the mapping does not require re-uploading the CSV – the report is rebuilt immediately with the new mapping.
